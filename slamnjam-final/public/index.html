ADMIN PANEL

📖 ADMIN USER MANUAL
⚡ Force Refresh
Manually pulls the latest scores from ESPN. Scores update automatically every 30 seconds — only use this if something looks stuck or stale.
🔒 Lock Round
Snapshots all current scores into seeds.json the moment a round's last game goes FINAL. This is the only action needed between rounds — no more code edits. After clicking, commit seeds.json to git so scores survive any future Render restart permanently.
🗑 Clear Round Data
Legacy button — only needed if you're still on the old HARDCODED_OVERRIDES workflow. If you're using 🔒 Lock Round you don't need this.
⚠ Never press mid-round — it will erase live pts.
🏆 Archive Season
Saves final standings to the Hall of Fame history. Use this only at the very end of the tournament after the champion is crowned.
🔄 New Season
Wipes rosters, scores, gamelog, bracket, and processed game data so the site is blank for a fresh draft. History is completely safe — Hall of Fame, champion rosters, and all prior year data are never touched. Requires typing "RESET" to confirm.
New Between-Round Workflow (Automated)
  1. Games run → site tracks pts live automatically ✓
  2. Last game of the round hits FINAL
  3. Press 🔒 Lock Round once
  4. Commit seeds.json to git → push to GitHub
  5. Done — scores are locked forever, next round starts clean ✓
No box score entry, no code edits, no manual overrides needed.
